Quadratic Functions

Learn how to understand, analyse and sketch quadratic graphs called parabolas.

Study Notes Worked Examples Practice

1. What is a Quadratic Function?

A quadratic function is a function whose highest exponent of x is 2.

General form:

f(x) = ax² + bx + c

where a ≠ 0

The graph of a quadratic function is called a parabola.

2. Understanding a, b and c

  • a: Determines whether the parabola opens upwards or downwards.
  • b: Helps determine the position of the turning point.
  • c: Gives the y-intercept.
If a is positive, the parabola opens upwards. If a is negative, the parabola opens downwards.

3. The Shape of a Parabola

A parabola can open upwards or downwards.

a > 0: Opens upwards (minimum turning point).

a < 0: Opens downwards (maximum turning point).

4. The Turning Point

The turning point is the highest or lowest point on the parabola.

For f(x) = ax² + bx + c, the x-coordinate of the turning point is:

x = -b / 2a

Substitute this x-value into the original function to calculate the y-coordinate.

5. Axis of Symmetry

The axis of symmetry is the vertical line that divides the parabola into two equal halves.

x = -b / 2a

6. The y-intercept

The y-intercept is where the graph crosses the y-axis.

To find it, let x = 0.

f(0) = c

Therefore, the y-intercept is (0 ; c).

7. The x-intercepts

The x-intercepts are where the parabola crosses or touches the x-axis.

To find them, let f(x) = 0 and solve:

ax² + bx + c = 0

You can use factorisation or the quadratic formula where appropriate.

8. How to Sketch a Parabola

  1. Identify a, b and c.
  2. Determine whether it opens upwards or downwards.
  3. Calculate the turning point.
  4. Find the axis of symmetry.
  5. Calculate the y-intercept.
  6. Find the x-intercepts, if they exist.
  7. Plot the points and draw the parabola.

9. Domain and Range

The domain is the set of possible x-values. For a standard quadratic function, the domain is all real numbers.

The range depends on the turning point and whether the parabola opens upwards or downwards.

If the minimum turning point is (p ; q), the range is y ≥ q.

If the maximum turning point is (p ; q), the range is y ≤ q.

10. Important Graph Features

  • Turning point
  • Axis of symmetry
  • x-intercepts
  • y-intercept
  • Direction of opening
  • Domain and range

1. Upward-opening Parabola

Example: f(x) = x²

2. Downward-opening Parabola

Example: f(x) = -x²

3. Shifted Parabola

Example: f(x) = (x - 2)² - 1
