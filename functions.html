1. Introduction to Functions

A function is a relationship between an input value and an output value. Each input must have exactly one output.

Function notation:

y = f(x)

The letter x represents the input, while f(x) represents the output.

2. The Straight-Line Function

A straight-line function is also called a linear function.

General equation:

f(x) = mx + c

  • m represents the gradient.
  • c represents the y-intercept.

If the gradient is positive, the line increases from left to right. If it is negative, the line decreases from left to right.

3. The Parabola

A parabola is the graph of a quadratic function. It has a turning point called the vertex.

General equation:

f(x) = ax² + bx + c

  • If a is positive, the parabola opens upwards.
  • If a is negative, the parabola opens downwards.
  • The turning point is the maximum or minimum point.

4. The Hyperbola

A hyperbola is a graph with two separate branches.

General equation:

f(x) = a/x + q

  • a controls the shape and orientation.
  • q shifts the graph vertically.
  • The graph has horizontal and vertical asymptotes.

5. The Exponential Function

An exponential function has the variable in the exponent.

General equation:

f(x) = a(b)ˣ + q

The graph can show exponential growth or decay, depending on the value of b.

6. The Logarithmic Function

A logarithmic function is related to an exponential function.

General equation:

f(x) = logb(x)

The logarithm tells us what exponent is needed to obtain a particular number.

7. Domain and Range

Domain: All the possible input values (x-values) of a function.

Range: All the possible output values (y-values) of a function.

8. Intercepts

  • x-intercept: Where the graph crosses the x-axis. At this point, y = 0.
  • y-intercept: Where the graph crosses the y-axis. At this point, x = 0.

9. Turning Points

A turning point is where a graph changes direction. For a parabola, it is called the vertex.

10. Transformations of Graphs

Transformations change the position, direction or shape of a graph.

  • f(x) + q: vertical shift.
  • f(x - p): horizontal shift.
  • -f(x): reflection across the x-axis.
  • f(-x): reflection across the y-axis.
