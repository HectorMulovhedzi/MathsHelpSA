Unit 1: Histograms

1. What is a Histogram?

A histogram is a graph used to display grouped numerical data. It uses bars that touch each other because the data is continuous.

2. Important Terms

  • Class interval: A group or range of values.
  • Frequency: The number of values in a class.
  • Class boundaries: The actual limits of a class.
  • Class width: The difference between the upper and lower class boundaries.

3. How to Draw a Histogram

  1. Place the class intervals on the horizontal axis.
  2. Place the frequency on the vertical axis.
  3. Choose a suitable scale for both axes.
  4. Draw a bar for each class interval.
  5. Make sure the bars touch each other.
  6. Give the graph a suitable title.
**For equal class widths:** The height of each bar represents its frequency.
**Remember:** Histogram bars touch each other. A bar graph usually has spaces between its bars.

Unit 2: Frequency Polygons

1. What is a Frequency Polygon?

A frequency polygon is a line graph that represents a frequency distribution. It is drawn by plotting the midpoint of each class interval against its frequency and joining the points with straight lines.

2. Finding the Class Midpoint

Class midpoint = (Lower class boundary + Upper class boundary) ÷ 2

For example, for the class 10 – 19:

Midpoint = (9.5 + 19.5) ÷ 2 = 14.5

3. How to Draw a Frequency Polygon

  1. Calculate the midpoint of every class interval.
  2. Place the midpoints on the horizontal axis.
  3. Place the frequencies on the vertical axis.
  4. Plot each midpoint against its frequency.
  5. Join consecutive points using straight lines.
**Remember:** A frequency polygon uses class midpoints, not the class intervals themselves.

Unit 3: Ogives

1. What is an Ogive?

An ogive is a cumulative frequency graph. It shows the running total of frequencies as the class intervals increase.

2. What is Cumulative Frequency?

Cumulative frequency is found by adding each frequency to the total of all the previous frequencies.

3. Example of a Cumulative Frequency Table

4. How to Draw an Ogive

  1. Calculate the cumulative frequency.
  2. Use the upper class boundaries on the horizontal axis.
  3. Use cumulative frequency on the vertical axis.
  4. Start at the lower boundary of the first class with cumulative frequency zero.
  5. Plot the points and join them with a smooth increasing curve or line segments.
**Remember:** An ogive must never decrease. Cumulative frequency stays the same or increases.

An ogive can be used to estimate the median, quartiles and the number of observations below or above a particular value.

Unit 4: Variance and Standard Deviation of Ungrouped Data

1. What is Ungrouped Data?

Ungrouped data is data presented as individual values rather than grouped into class intervals.

2. Mean

Mean = Sum of all values ÷ Number of values

3. Variance

Variance measures how far the data values are spread out from the mean.

Population variance: σ² = Σ(x − x̄)² ÷ n

Here, x is an individual value, x̄ is the mean, and n is the number of values.

4. Standard Deviation

Standard deviation measures the typical spread of values around the mean.

Standard deviation: σ = √Variance

5. Steps to Calculate Variance

  1. Calculate the mean.
  2. Subtract the mean from each value.
  3. Square each difference.
  4. Add all the squared differences.
  5. Divide by the number of values, n, when treating the data as a population.
**Important:** Use the formula and divisor specified in the question. Population variance divides by n; sample variance divides by n − 1.

Unit 5: Symmetrical and Skewed Data

1. Symmetrical Distribution

A symmetrical distribution has two sides that are approximately mirror images of each other around the centre.

  • The mean, median and mode are approximately equal.
  • The left and right sides have similar shapes.

2. Positively Skewed Distribution

A positively skewed distribution has a longer tail extending to the right.

  • Most values are concentrated on the left.
  • The mean is usually greater than the median.
  • The median is usually greater than the mode.

3. Negatively Skewed Distribution

A negatively skewed distribution has a longer tail extending to the left.

  • Most values are concentrated on the right.
  • The mean is usually less than the median.
  • The median is usually less than the mode.
**Remember:**
  • Positive skew: tail points right.
  • Negative skew: tail points left.
  • Symmetrical: both sides are balanced.

Unit 6: Identifying Outliers

1. What is an Outlier?

An outlier is a value that is unusually far from the other values in a data set.

2. Quartiles

  • Q₁: Lower quartile.
  • Q₂: Median.
  • Q₃: Upper quartile.

3. Interquartile Range (IQR)

IQR = Q₃ − Q₁

The IQR measures the spread of the middle 50% of the data.

4. The Outlier Rule

Lower boundary = Q₁ − 1.5(IQR) Upper boundary = Q₃ + 1.5(IQR)

A value below the lower boundary or above the upper boundary is identified as an outlier using this rule.

5. Worked Illustration

Suppose:

  • Q₁ = 10
  • Q₃ = 20

IQR = 20 − 10 = 10

Lower boundary = 10 − 1.5(10) = -5

Upper boundary = 20 + 1.5(10) = 35

Therefore, any value below -5 or above 35 is an outlier according to this rule.

6. Box-and-Whisker Plot

A box-and-whisker plot displays the minimum, lower quartile, median, upper quartile and maximum. Outliers are shown separately.

Box-and-Whisker Plot

The isolated point represents an outlier.

**Remember:** Always calculate the IQR first before applying the outlier rule.
