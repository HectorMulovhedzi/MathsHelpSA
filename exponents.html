1. Introduction to Exponents

Exponents show how many times a number is multiplied by itself.

Example:

2³ = 2 × 2 × 2 = 8

2. Basic Exponent Rules

Multiplication Law

aᵐ × aⁿ = aᵐ⁺ⁿ

When multiplying powers with the same base, add the exponents.

Division Law

aᵐ ÷ aⁿ = aᵐ⁻ⁿ

When dividing powers with the same base, subtract the exponents.

Power of a Power

(aᵐ)ⁿ = aᵐⁿ

Multiply the exponents.

Zero Exponent

a⁰ = 1, where a ≠ 0

Any non-zero number raised to the power of zero equals one.

Negative Exponent

a⁻ⁿ = 1/aⁿ

A negative exponent means the reciprocal of the positive power.

Fractional Exponent

a¹/ⁿ = ⁿ√a

A fractional exponent represents a root.

3. What Are Surds?

A surd is a root that cannot be simplified to a rational number.

Examples include √2, √3 and √5.

4. Surd Rules

Multiplication of Surds

√a × √b = √(ab)

Division of Surds

√a ÷ √b = √(a/b)

Where b is positive.

Square Root of a Square

√(a²) = |a|

5. Simplifying Surds

To simplify a surd, look for a perfect square factor inside the root.

Example:

√12 = √(4 × 3)

= √4 × √3

= 2√3

6. Adding and Subtracting Surds

You can only add or subtract like surds. Like surds have the same number inside the root.

Example:

2√3 + 5√3

= 7√3

Remember: You cannot combine unlike surds directly.

2√3 + 5√2 cannot be simplified further.
