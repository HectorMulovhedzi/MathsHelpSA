Unit 1: Combinations of Events

1. What is an event?

An event is an outcome or a group of outcomes that we are interested in during an experiment.

Example:

When rolling a die:

A = getting an even number

A = {2, 4, 6}

2. Union of events (A ∪ B)

The union of A and B means that event A happens, event B happens, or both events happen.

Addition Rule:

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

Remember to subtract the intersection because it is counted twice when adding P(A) and P(B).

3. Intersection of events (A ∩ B)

The intersection means that both events happen at the same time.

Example: A number is even and greater than 3 when rolling a die.

A ∩ B = {4, 6}

4. Complement of an event

The complement of A means that event A does not happen.

Complement Rule:

P(A') = 1 − P(A)

5. Mutually exclusive events

Two events are mutually exclusive if they cannot happen at the same time.

P(A ∩ B) = 0

P(A ∪ B) = P(A) + P(B)

6. Non-mutually exclusive events

These events can happen at the same time. Their intersection must be subtracted when using the addition rule.

Unit 2: Dependent and Independent Events

1. Independent events

Two events are independent if the outcome of the first event does not affect the probability of the second event.

Example: Tossing a coin twice. The first toss does not affect the second toss.

Multiplication Rule:

P(A ∩ B) = P(A) × P(B)

2. Dependent events

Two events are dependent if the outcome of the first event affects the probability of the second event.

Example: Selecting two balls from a bag without replacing the first ball.

Multiplication Rule:

P(A ∩ B) = P(A) × P(B given A)

P(A ∩ B) = P(A) × P(B | A)

3. Conditional probability

Conditional probability is the probability of event B happening when we already know that event A has happened.

Conditional Probability:

P(B | A) = P(A ∩ B) / P(A)

4. Replacement and no replacement

With replacement:

The item is returned before the next selection. The probabilities stay the same.

Without replacement:

The item is not returned. The total number of items changes, so the probabilities may change.

Exam tip: Always check whether the question says "with replacement" or "without replacement".

Unit 3: Tree Diagrams

1. What is a tree diagram?

A tree diagram is a diagram that shows all possible outcomes of a sequence of events.

It is useful when an experiment involves two or more stages.

2. Important rules

Multiplying along branches:

Multiply probabilities along a path to find the probability of that sequence.

Adding separate paths:

Add the probabilities of different paths when they represent alternative ways for the required event to happen.

3. Example: Tossing a coin twice

A fair coin is tossed twice. Each toss has two possible outcomes: Heads (H) or Tails (T).

First toss: H = 1/2, T = 1/2

Second toss: H = 1/2, T = 1/2

Possible outcomes: HH, HT, TH, TT

Probability of getting two heads:

P(HH) = 1/2 × 1/2

P(HH) = 1/4

4. Tree diagrams without replacement

When selecting objects without replacement, the probabilities on the second set of branches change because the first object is not returned.

Remember: The probabilities leaving each point on a complete tree diagram must add up to 1.
